# Chataigne documentation

The complete, current Chataigne documentation is available at
<https://docs.chataigne.io/>. Use the upstream site's navigation and search to
browse the full documentation rather than treating the topics currently used
by this repository as an exhaustive index.

Related authoritative resources:

- [Chataigne source code and releases](https://github.com/benkuper/Chataigne)
- [Chataigne website](https://chataigne.io/)

## Why the documentation is linked

This repository links to the maintained upstream documentation instead of
copying it. A copy would become stale as Chataigne changes and could hide newly
documented capabilities—the opposite of this repository's goal of supporting
experimentation across the full feature set. A live link also avoids carrying
duplicate content and remains the canonical source selected by the Chataigne
maintainers.

The trade-off is that the reference requires internet access. If repeatable
work against a particular Chataigne release later requires offline docs, add a
clearly versioned snapshot while retaining this live reference for discovery.
