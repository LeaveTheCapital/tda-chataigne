# Repository purpose

This repository is a Chataigne experimentation workspace. The existing SysEx
scripts are retained as historical reference, but new work should focus on
using Chataigne to connect and automate devices and media, including:

- controlling lighting;
- triggering audio, video, and other media;
- translating controller input, such as a wireless Nintendo Wii controller,
  into MIDI CC messages sent through a virtual MIDI port; and
- exploring other capabilities and integrations supported by Chataigne.

# Chataigne reference documentation

Consult [`docs/README.md`](docs/README.md) and the complete upstream Chataigne
documentation before implementing an experiment. Upstream documentation is the
source of truth; keep the repository reference linked to it so new and updated
features remain discoverable.

Do not copy the entire documentation into this repository unless an offline or
version-pinned snapshot becomes a concrete requirement. If a snapshot is
needed, record its upstream version or commit and preserve its licence and
attribution.
